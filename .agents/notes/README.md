# Agent Notes

记录 agent 参与开发过程中的重要设计决策。路径格式：

```
.agents/notes/<lifecycle>/<class>/YYYY-MM-DD-<topic>.md
```

- `lifecycle`：`proposed`（提案）/ `implemented`（已落地）/ `rejected`（已否决，保留备查）
- `class`：`feature` / `architecture` / `bug-fix` / `simplification` / `testing` / `process`
- 标题即结论；正文三段：背景（为什么需要决策）、决策（选了什么、为什么）、后果（带来的约束与影响）。
- 只增不删；决策反转时新增一条并在正文引用旧条目。
